A **minimal but genuinely usable** Obsidian vault skeleton — the free taster.
It gives you a clean PARA folder spine, a daily note, and one weekly review, so
you can feel the system working in minutes.

## What's in the free edition

- **PARA spine** — Inbox, Projects, Areas, Resources, Archive
- **Daily note** with yesterday→today carry-over
- **Weekly review** template
- Valid `.obsidian` config — opens as a vault immediately
- MIT licensed

## Install (under 60 seconds)

1. Obsidian → **Open folder as vault** → pick this folder.
2. Point the core **Daily Note** plugin at `Templates/Daily Note.md`.
3. Start capturing.
